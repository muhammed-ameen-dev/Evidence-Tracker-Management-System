# Evidence Tracker Management System (SDEMS)

## Overview

Evidence Tracker Management System (SDEMS) is a Django-based web application designed to manage cases, evidence records, and investigation workflows efficiently. The system provides a centralized platform for tracking digital evidence, managing case information, and controlling user access.

---

## Features

* User Authentication & Authorization
* Case Management
* Evidence Tracking
* Investigation Workflow Management
* Dashboard Interface
* Secure Data Storage
* Role-Based Access Control

## Installation

```bash
git clone https://github.com/muhammed-ameen-dev/Evidence-Tracker-Management-System.git

cd Evidence-Tracker-Management-System

pip install -r requirements.txt

python manage.py migrate

python manage.py runserver
```

Open:

http://127.0.0.1:8000/
