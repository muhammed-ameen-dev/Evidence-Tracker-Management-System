# 🔐 Secure Digital Evidence Management System (SDEMS)

## 📖 Overview

Secure Digital Evidence Management System (SDEMS) is a Django-based web application designed to securely manage digital evidence, organize case information, and streamline investigation workflows through a centralized platform. The system helps investigators and authorized personnel efficiently track evidence, manage cases, and maintain secure records throughout the investigation lifecycle.

---

## ✨ Features

* 🔐 User Authentication & Authorization
* 📂 Case Management
* 📝 Digital Evidence Tracking
* 👥 User Management
* 📊 Investigation Workflow Management
* 📋 Audit Tracking
* 🛡️ Secure Data Storage
* 🎯 Role-Based Access Control
* 🖥️ Responsive Web Interface

## 🚀 Installation & Setup

### Clone the Repository

```bash
git clone https://github.com/muhammed-ameen-dev/Secure-Digital-Evidence-Management-System.git
```

### Navigate to Project Directory

```bash
cd Secure-Digital-Evidence-Management-System
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Apply Migrations

```bash
python manage.py migrate
```

### Run Development Server

```bash
python manage.py runserver
```

### Open in Browser

```text
http://127.0.0.1:8000/
```
